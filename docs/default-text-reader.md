# שילוב כקורא ברירת מחדל באוצריא

מבוסס על `docs/plugin-sdk/DEFAULT_TEXT_READER.md` בריפו של אוצריא (ענף dev).

- הפעלה: `reader.setDefaultTextReader({enabled})` מתוך מחוות משתמש (מתג בהגדרות; ניסיון אוטומטי בלחיצה הראשונה).
- מופע משובץ מזוהה ב-`plugin.boot` לפי `reader.embedded`; הספר נטען לפי `bookId`/`bookUid`, קפיצה ל-`currentIndex`, הדגשת `searchQuery`.
- `reader.textReaderNavigate`: ניווט; נשמר ב-`PEND` אם הספר עוד בטעינה. אירועים של ספר אחר מסוננים (`sameBook`).
- `reader.textReaderCommand`: `advance`, `settings`, `display` (גודל אות/ניקוד).
- `reader.reportTextReaderLocation({index, ref})`: אחרי גלילה (debounce 600ms), `ref` = כותרת תוכן העניינים הקרובה.
- `reader.setTextReaderFontSize`: בשינוי גודל אות במצב משובץ (טווח 14–60).
- חזרה לעיון רגיל: `reader.openBook({..., reader:'native'})`.
- חל רק על ספרי text; PDF/EPUB/DOCX נשארים בקורא המובנה.

## למה 1.4.2 לא הפעיל את הקורא
- אוצריא בודקת `navigator.userActivation.isActive`. ההפעלה רצה על `pointerdown`, שבמגע אינו נחשב מחוות משתמש, ולפני כן חיכתה ל-`getDefaultTextReader`. עכשיו: `click`/`keydown`, וקריאה ישירה ל-`setDefaultTextReader`.
- המתג בהגדרות הציג "מופעל" לפי ברירת המחדל המקומית גם כשבאוצריא היה כבוי, כך שאי אפשר היה להפעיל. עכשיו הוא משקף את `getDefaultTextReader`.
- כפתור שדה האיתור דורש `search.field_actions` + `contributes.startup.searchFieldActions` ו-`minAppVersion` 0.9.99; ב-1.4.2 שניהם חסרו.

## תאימות גרסאות (נבדק 03.11.2026)
- `search.field_actions` ו-`searchFieldActions` קיימים בקוד אוצריא מתג 0.9.98.2+807 (וגם 0.9.98.3+809); בתג 0.9.98+801 אינם — שם ההתקנה נדחית ("הרשאה לא חוקית").
- אוצריא מדווחת לתוספים גרסה של 3 חלקים בלבד (`0.9.98`, בלי ה-hotfix), ולכן `minAppVersion: "0.9.98.3"` היה חוסם את כולם. הבנייה שבתיקייה `src-0.9.99` (1.5.3) מוגדרת `minAppVersion: "0.9.98"`; משתמשי 0.9.98 המקורית (801) צריכים לעדכן ל-0.9.98.3 או להתקין את הבנייה מ-`src` (1.5.1).

## 2.0.0 – החלפת קורא באותה כרטיסייה (04.11.2026)
- גרסה אחת בלבד בתיקייה `src` (minAppVersion 0.9.98.3, מאושר שמותקן ועובד). `src-0.9.99` הוסרה.
- פקד הסרגל `reading-mode-toggle` (בלי `openPlugin`) מטופל ב-`toggleReader`:
  - מצב נוכחי = משובץ אם מופע משובץ של אותו ספר כתב `live:i<id>` / `live:b<bookId>` באחסון ב-8 השניות האחרונות (פעימה כל 3 שניות, `startBeat`). אין API שמחזיר האם כרטיסייה מוצגת בקורא התוסף.
  - משובץ → `reader.openBook({..., reader:'native'})`.
  - רגיל → אין API שמבטל את עקיפת ה-native בכרטיסייה חיה (`useNative` חד-כיווני ב-PluginTextReaderRegistry), לכן: `reader.closeTab` לכרטיסייה ואז `reader.openBook` רגיל – כרטיסייה חדשה נפתחת בקורא התוסף באותו אינדקס.
  - קורא ברירת מחדל כבוי → פתיחה בלשונית התוסף + הודעה.
- לחצן `#rNative` בסרגל הקריאה של התוסף: פתיחה בקורא הרגיל באותו מקום.
- פרסום לחנות: `.github/workflows/store.yml` (סודות OTZARIA_USER / OTZARIA_PASSWORD נדרשים בריפו), יוצר גם Release עם קובץ ה-otzplugin.

## 2.1.0 – סדר בממשק, חלוקה לעמודים מהירה (04.11.2026)
- **חלוקה מעוגנת:** `anchorAt` מתחיל את החלוקה בכותרת הקרובה (עד 300 מקטעים אחורה) שלפני מקום הקריאה. הקטע הקודם נבנה ברקע ב-`tb.back` (`buildPage(tb,seg)` עם `{p,end,pending}`), ובסיומו `mergeBack` מצרף את כל העמודים בבת אחת ומתקן את הגלילה (snap ו-overflow-anchor מושבתים לשתי פריימים — אחרת כרום מקפיץ את הגלילה). `pump` בונה קודם 8 עמודים קדימה ואז את הקטע הקודם. מעבר למקטע שלפני העוגן: אם נבנה ≥60% → `finishBack`, אחרת `reanchor`; קפיצה רחוקה קדימה (>150 מקטעים) → `reanchor`.
- `pump` שנקרא בזמן ש-pump אחר רץ נשמר ב-`pumpReq` ומופעל בסיום (בעבר נבלע, והחלוקה נעצרה אחרי שינוי הגדרה).
- **מספרי עמודים:** "עמוד X מתוך Y" רק כשהכול סודר; בזמן החלוקה – אחוז ב-`#pstat` (לא הערכה קופצת). מספרי עמודים ליד כותרות תוכן העניינים. מעבר לעמוד: `#pinfo` / Ctrl+G (`openJump`). אין API להכניס עמודים לחלונית הניווט של אוצריא.
- **גלילה למטה:** קו דק בין עמודים ומספר עמוד (CSS counter, רק כש-`#strip.pnok`).
- **סרגל אוצריא:** `reading-mode-toggle` הוא `type:"split"`. ראשי = החלפת קורא; ילדים `rm-clean`, `rm-mode`, `rm-cols`, `rm-page`, `rm-report`. האירוע נשלח למופע הראשי/רקע של התוסף (`dispatchEventToPlugin(preferBackground:true)` בקוד אוצריא), לא למופע המשובץ — לכן `routeCmd` מעביר דרך `localStorage['wr:cmd']` ({id,bookId,c,t,n}); המופע המשובץ מאזין ל-`storage` וגם בודק כל 400ms. אם הכרטיסייה בקורא הרגיל — קודם `toggleReader` ואז הפקודה. `syncTbMenu` מעדכן את שם/אייקון ילד הכיוון (`reader.updateToolbarItem`, שגיאה נבלעת).
- במשובץ הוסר `#top` (מסך נקי/גלילה/הגדרות — כפולים לסרגל אוצריא ול"הגדרות קורא התוסף"), ומהשורה התחתונה הוסרו חצים ו-א±. "מעבר לקורא רגיל" בתפריט "עוד" הוא של אוצריא ואי אפשר להסירו.
- כיוון הגלילה (`mode`) נשמר ב-`settings`; האייקון משתנה לפי הכיוון.
- דיווח: `feedback.report` מתוך ההגדרות (תקלה/אחר), עם הקשר (גרסה, ספר, מקטע, מצב).
- ייצוא לוורד כולל שורת הורדה (GitHub + חנות אוצריא).
- בדיקה: מוק של `window.Otzaria` + Playwright (ספר 3000 שורות, פתיחה באמצע): עמוד ראשון ~0.1 שניות, מיזוג ~1 שנייה, המיקום נשמר.
